# 仓颉 Python 互操作库 API

为了兼容强大的计算和 AI 生态，仓颉支持与 Python 语言的互操作调用，仓颉-Python 互操作库为用户提供该能力。

目前 Python 互操作仅支持在 Linux 平台使用，并且仅支持仓颉编译器的 cjnative 后端。

## 包列表

仓颉 Python 互操作库只包含 py_interop 一个包：

| 包名                                                                           | 功能                                                                                                                                                                                  |
| ------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [py_interop](./py_interop/py_interop_package_overview.md)                      | py_interop 包提供仓颉与 python 跨语言互操作能力。                                                                                                                                     |
